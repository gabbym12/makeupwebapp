This project is an online makeup shop with a separate five-game arcade: Shade
Match, Makeup Memory Match, One-Take Memory, Beauty Trivia, and Build a Makeup
Look. One-Take Memory grows from 6 to 10 pairs over three rounds; one miss
restarts the whole run. Each round has a fixed layout, with later rounds moving
the cards while preserving matching pairs. Standard Memory Match remains
forgiving.

**Why:** The user asked for more than color matching, selected three additional games, requested a restart-on-mistake card game, then asked for two larger, harder rounds with cards moved to different places between rounds.

**How to apply:** Preserve the shop at `/`; keep the five activities together on the separate game page and retain three escalating rounds with stable, pair-correct layouts that differ by round unless the user changes direction.
