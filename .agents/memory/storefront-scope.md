This project is an online makeup shop with a separate five-game arcade: Shade
Match, Makeup Memory Match, One-Take Memory, Beauty Trivia, and Build a Makeup
Look. One-Take Memory restarts a run after a wrong pair, while standard Memory
Match remains forgiving.

**Why:** The user asked for more than color matching, selected three additional games, then requested a separate restart-on-mistake card game.

**How to apply:** Preserve the shop at `/` and keep the five activities together on the separate game page unless the user changes direction.
